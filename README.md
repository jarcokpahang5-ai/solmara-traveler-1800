# solmara-traveler-1800

One line for make.fun's "One Sentence for a Traveler from 1800" bounty: the modern internet pictured as one great invisible library that answers the moment you ask. `main.py` prints the line and writes it to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```
